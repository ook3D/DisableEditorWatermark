# DisableEditorWatermark

Disables:
- Rockstar Editor render watermark
- FiveM corner branding (`FiveM* (bXXXX)`, `Ver. XXXXX`, emoji)
- FiveM `X mod packs loaded` overlay from graphic packs or client mod

## Install

- **GTA V / Rockstar Editor:** drop `DisableEditorWatermark.asi` into the game root (ScriptHookV)
- **FiveM:** drop `DisableEditorWatermark.asi` into `%localappdata%\FiveM\FiveM.app\plugins`
